Use one API to ship reliable astrology experiences faster — from a first prototype to a customer-facing application.

## One API, a complete astrology toolkit

- **Natal astrology** — subjects, birth charts, houses, aspects, dignities, dominants, and distributions
- **Relationship astrology** — synastry, compatibility scoring, midpoint and Davison composite charts
- **Predictive techniques** — transits, solar and lunar returns, secondary progressions, solar arcs, primary directions, profections, firdaria, and zodiacal releasing
- **Astrological timing** — lunations, eclipses, retrograde stations, sign ingresses, void-of-course Moon, planetary hours, and astro calendars
- **Specialized calculations** — astrocartography, fixed stars, planetary nodes, heliacal events, occultations, declination aspects, midpoints, and ephemerides
- **Beautiful SVG charts** — classic and modern layouts, light and dark themes, customizable colors, split wheel/grid output, and transparent backgrounds
- **AI-ready output** — structured context designed for LLMs, assistants, and astrology agents
- **REST and MCP** — use the API from traditional applications or connect it directly to compatible AI tools

## Precision you can inspect

The API is powered by [Kerykeion](https://github.com/g-battaglia/kerykeion) and libephemeris. Responses can include calculation provenance and precision metadata, making it possible to understand which astronomical source produced each result.

The v6 engine is being validated across modern, historical, and deep-time calculations before public launch.
